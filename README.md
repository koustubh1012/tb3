# TurtleBot3 (ROS 2 Jazzy)

Setting up and running a TurtleBot3 Burger on ROS 2 Jazzy, with SLAM and navigation.

- **Setup:** [setup-guide.md](setup-guide.md)
- **Progress and open issues:** [logs.md](logs.md)
- **Laptop environment:** `Dockerfile` + `compose.yaml`. Run `docker compose up -d --build`, then `docker compose exec tb3 bash`.

## Contributing
1. Create a branch, make your change, and open a pull request.
2. Add a short entry to the top of `logs.md` saying what you did.
3. If you change a setup command, update `setup-guide.md` too.
